Real-Life Patch Notes: The Comedy Changelog — Write the funniest one-line patch note, 160 characters max, for a bug in real life or human biology, in the terse register of a real release note. A house judge compares lines two at a time on patch-note form, funniness, release-note register, specific recognisable bug, then tightness. Free entry, $5 pool split equally across the top 5. Entries close 2026-11-27 05:20 WIB; blind rounds, results due 2026-12-19.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt`.
